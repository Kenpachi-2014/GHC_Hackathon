# Expense Tracker Application - Frontend

This is the frontend part of the Expense Tracker application, built using React and TypeScript. The application allows users to track their expenses, generate reports, and share expenses with others.

## Features

- **Add and Update Expenses**: Users can easily add new expenses and update existing ones.
- **Download Reports**: Generate and download expense reports for analysis.
- **Expense History**: Maintain a history of all expenses for tracking purposes.
- **User Sharing**: Share expenses with multiple users for collaborative tracking.
- **Analytics**: Run analytics on the expense data to gain insights.

## Project Structure

- **public/index.html**: Main HTML file for the application.
- **src/App.tsx**: Main component that sets up routing and application structure.
- **src/index.tsx**: Entry point for rendering the React application.
- **src/components**: Contains reusable components like ExpenseForm and ExpenseList.
- **src/pages**: Contains page components such as HomePage and ReportPage.
- **src/services**: Contains service files for API calls to the backend.
- **src/styles**: Contains styles for the application.
- **package.json**: npm configuration file for managing dependencies and scripts.
- **tsconfig.json**: TypeScript configuration file.

## Getting Started

1. Clone the repository.
2. Navigate to the `frontend` directory.
3. Install dependencies using `npm install`.
4. Start the development server with `npm start`.
